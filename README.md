# Email Risk Analyzer

A Python tool built for the VirtualWorks Cyber Security Internship (Task 3) that scans email text to detect potential phishing and social engineering indicators.

## Features
- **Urgency Detection:** Flags high-pressure phrases designed to rush the reader.
- **Sensitive Data Monitoring:** Identifies prompts asking for passwords, OTPs, or financial details.
- **Link Inspection:** Extracts embedded URLs and highlights raw IP addresses or link shorteners.
- **Risk Classification:** Categorizes emails into **Low**, **Medium**, or **High Risk**.
